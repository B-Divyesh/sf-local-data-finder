How it works

Search records you choose.

Local Data Finder builds an index from the folders and exports you select. Each match includes its path and extraction time.

  1. 01

    Choose the boundaries

    Add only specific folders or explicit exports. Hidden folders and unsupported files are skipped.

  2. 02

    Build a local evidence map

    Text is extracted on-device from Markdown, plain text, HTML, mbox and text-based PDFs. Mail attachments stay closed.

  3. 03

    Search, inspect, open

    Filter local text matches, read the surrounding evidence, then open the original local source.

# Demo sandbox

Open `/demo/` from the site, or choose **Load sample project** on the first desktop-app screen.

The sample contains a Markdown migration plan, an HTML field note, and an mbox message. Search `MAPLE-742`, `Northwind`, or `original export` to see a source-grounded match. The desktop sample uses `demo-index.json` and the `demo-sample` directory below the app data directory; it never reads or writes the normal index. **Reset demo** recreates those records. **Start for real** removes both demo artifacts before the visitor chooses a source.

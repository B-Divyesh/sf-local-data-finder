Privacy

Local Data Finder processes selected records on your device.

Desktop app

Selected paths, extracted text, search queries, and index settings stay on your device. The app does not send your selected files, paths, or search queries to a service. Opening a source uses your operating system.

Website

The site has no ads, tracking, or font downloads from other companies. The landing page caches public GitHub release information for one hour.

Your control

Remove a source to remove its extracted records from the index. This does not delete the original files. The desktop sample uses a separate local index and is discarded when you start for real. The browser demo stores its query under a separate demo key. It clears when you start for real.

Contact

File privacy questions in the public project repository. Do not include archive content.
